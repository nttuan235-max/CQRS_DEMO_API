# CQRS_DEMO
A C# Backend learning project built with ASP.NET Core Web API.
Technologies

C#

ASP.NET Core Web API

CQRS and MediatR

AutoMapper

FluentValidation

Dapper

Oracle Database

REST API and JSON

Features

Retrieve users from Oracle

Retrieve a user by ID

Create a user

Validate incoming requests

Handle application exceptions

Prerequisites

.NET SDK compatible with the project

Oracle Database

Oracle SQL Developer (optional)

Configuration

Configure the Oracle connection string using .NET User Secrets.

The configuration key is ConnectionStrings:Oracle.

Do not commit real database passwords or other secrets.

Running the project

Clone the repository.

Configure the Oracle connection string.

Restore NuGet packages.

Run the project in Visual Studio.

Test the API using the project's HTTP request file or Postman.

Purpose

This project is for learning C# Backend development and practicing database access, validation, and CQRS architecture.
